# 02 · Lista — ion-list + ion-item

Tres formas de usar `ion-list`, una sección por concepto:

1. **Ítems clickeables** — `button="true"` (se ven tocables) + `detail="true"` (flecha `>`).
2. **Avatar / thumbnail** — `ion-avatar` (foto redonda) y `ion-thumbnail` (imagen cuadrada) en `slot="start"`.
3. **Deslizables (swipe)** — `ion-item-sliding` + `ion-item-options`: arrastra el ítem para revelar acciones.

En standalone los íconos se registran con `addIcons(...)`.

**Archivos clave:** `src/app/home/home.page.html` y `home.page.ts`
